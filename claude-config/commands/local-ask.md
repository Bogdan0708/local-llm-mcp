description: Delegate a task to the local LM Studio model (conserves Claude usage)
---

Use the local_ask MCP tool to delegate the user's task to the local model: coding questions, code or document summaries, commit-message drafts, and data extraction/transformation.

Rules:
1. Review the local model's output yourself before presenting or using it — correct or redo anything inadequate.
2. If the local model is unavailable, do the work yourself and say so once. Never retry the local model in a loop.
